# NeNe Sand

WSL の Ubuntu 端末で、マウスで砂を描いて遊ぶシミュレーター。Swift 製。コマンド名は `nene-sand`。

このリビジョンは、砂と水と油と火と木と溶岩を描く版と、それを守るゲートである。`a` で勝手に描き、砂と水と油と火と木と溶岩が線ごとに入れ替わる。火は油と木に燃え移り、水で消える。溶岩は水よりゆっくり流れ、油と木に火をつける。水に触れた溶岩は石になり、石は落ちて溜まる。初めて石ができてから `7` で石を描ける。右クリックは、左クリックと同じ道を空にする。`c` で盤の粒を全部消す。`Space` で粒の流れと自動描画が止まり、マウスで置くことと消すことはできる。進行、セーブはまだ無い。

完了の定義は次の 1 コマンドである。

```bash
make check
```

Swift の版は `.swift-version` だけに書く。開発の入口は [CLAUDE.md](CLAUDE.md) と [AGENTS.md](AGENTS.md)。
