# NeNe Sand

WSL の Ubuntu 端末で、マウスで砂を描いて遊ぶシミュレーター。Swift 製。コマンド名は `nene-sand`。

このリビジョンは、砂と水と油と火と木と溶岩を描く版と、それを守るゲートである。`a` で勝手に描き、砂と水と油と火と木と溶岩が線ごとに入れ替わる。火は油と木に燃え移り、水で消える。溶岩は水よりゆっくり流れ、油と木に火をつける。水に触れた溶岩は石になり、石は落ちて溜まる。初めて石ができてから `7` で石を描ける。右クリックは、左クリックと同じ道を空にする。`c` で盤の粒を全部消す。`Space` で粒の流れと自動描画が止まり、マウスで置くことと消すことはできる。`[` `]` で筆は 1、3、5 マスの正方形になる。`m` で自由に遊ぶと、反応の前でも石を描ける。盤の上に 3 行、下に 3 行の英語の計器が出る。色見本と状況と冗談と、キーの説明である。`t` で 12 のテーマを一周する。水はどのテーマでも青のまま。進行モードでは底の中央が回収口で、そこにいる粒は次の tick で消え、計器に `$` と金額が出る。砂 1、水 2、石 4、木 8、油 16、火 0、溶岩 32。自由に遊ぶでは増えない。進行の最初は砂と水だけ。`3` で油を 40、`5` で木を 20、`6` で溶岩を 80 買う。足りなければ何も起きない。火は、溶岩が油か木に着火すると解放され、そのあと `4` で描ける。`f` で蛇口を 60 で一度だけ買う。持っていると、上の中央が空のとき水が 1 粒落ちる。自由に遊ぶでは買わず、水も落ちない。自由に遊ぶでは全部描ける。セーブはまだ無い。

完了の定義は次の 1 コマンドである。

```bash
make check
```

Swift の版は `.swift-version` だけに書く。開発の入口は [CLAUDE.md](CLAUDE.md) と [AGENTS.md](AGENTS.md)。
