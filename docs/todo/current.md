## 動くもの

`make check`。中身は規約検査、その単体テスト、コミットメッセージ、`swift build`、`swift test`、swift-format、SwiftLint である。

砂と水と油と火は左クリックとドラッグで描ける。`1` が砂、`2` が水で、左上に「砂」か「水」が出る。`a` で自動描画を切り替える。オンのあいだは、砂、水、油、火を線ごとに入れ替えながらマウスと同じ道で置き、左上に「自」と今の物質が出る。`3` が油で、左上に「油」が出る。油は水と同じく流れて、水の上に浮く。油と水の境は水平に寄る。水と砂は油に沈む。`4` が火で、左上に「火」が出る。火は空なら斜め上を先に試して揺れながら上へ行き、48 tick で消える。砂は落ちて積もり、水に沈む。水は落ち、斜め下へずれ、水面の粒だけが低い方へ流れる。平らになると止まり、左右に往復しない。外の空気とつながっていない空席は、同じ tick で上の粒が落ちてふさがる。`q` と `Ctrl+C` で終了し、端末と標準入力のフラグを戻す。未読の入力は捨てる。極小の端末では「小さすぎる」と 1 行出して待つ。`5` から `7`、消去、一時停止、筆の太さ、自由に遊ぶは、まだ結線していない。自動描画の `a` と印の「自」と、油と火の色と、火の寿命は、実装側の選択である。

| | |
| --- | --- |
| 終了 | `q` と `Ctrl+C`。どちらでも端末を戻す |
| 物質 | `1` 砂、`2` 水、`3` 油、`4` 火、`5` 木、`6` 溶岩、`7` 石。HUD に今の物質を出す。砂と水と油と火は描ける。木と溶岩の入手は未決。石の `7` は、水と溶岩の反応を初めて起こしてから |
