## 動くもの

`make check`。中身は規約検査、その単体テスト、コミットメッセージ、`swift build`、`swift test`、swift-format、SwiftLint である。

砂と水は左クリックとドラッグで描ける。`1` が砂、`2` が水で、左上に「砂」か「水」が出る。砂は落ちて積もり、水に沈む。水は落ち、斜め下へずれ、横へ流れる。`q` と `Ctrl+C` で終了し、端末を戻す。極小の端末では「小さすぎる」と 1 行出して待つ。`3` から `7`、消去、一時停止、筆の太さ、自由に遊ぶは、まだ結線していない。

## 決まった操作

2026-10-25 に施主が決めた。結線しているのは、終了、左クリックで描くこと、`1` の砂、`2` の水、左上の物質名である。

| | |
| --- | --- |
| 終了 | `q` と `Ctrl+C`。どちらでも端末を戻す |
| 物質 | `1` 砂、`2` 水、`3` 油、`4` 火、`5` 木、`6` 溶岩、`7` 石。HUD に今の物質を出す。最初に描けるのは砂と水。石の `7` は、水と溶岩の反応を初めて起こしてから |
| 盤面 | 右クリックで消す。`c` で全消去。`Space` で一時停止。`[` `]` で筆の太さ |
| 石 | 描ける。壁など他の固体は足さない。下へ落ちて溜まる |
| 閉じている間 | 進まない |
| 自由に遊ぶ | 残す。全部解放で、通貨は無い。プレイ中の `m` で進行モードと切り替える |
| 装置 | 最初は蛇口だけ。ほかの種類と値段と倍率は、触れてから |
