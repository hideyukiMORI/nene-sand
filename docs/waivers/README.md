# 規則の waiver

waiver は、1 つの名前のある機械規則に対する、期限付きで最小範囲の例外である。別のアーキテクチャではない。

Swift は抑制を言語で封じられない。`swiftlint:disable` と `swift-format-ignore` は理由なしで効くことを実測した。だから台帳を持つ。コンパイラに警告抑制の pragma は無い。

## 原則

- waiver は最後の手段である。先に正典の実装経路を試す
- 1 つの規則、1 つの理由、可能な限り小さい範囲に閉じる
- Issue、担当、作成日、期限を持つ
- コードの抑制の直前行と PR 本文の両方から参照する
- 期限切れの waiver はゲートを落とす（CNF-004）
- 恒久化した waiver は、コードを直して消すか、規則を変える ADR に置き換える

lint の baseline、ディレクトリ単位の除外、全面抑制は禁止であり、waiver でも許可できない（QLT-003 / CNF-005）。

## waiver で緩められないもの

依存方向、単一のゲート、警告はエラー、依存の再現性。これらは ADR でも緩められない。

## 命名

```text
WVR-NNNN-short-kebab-title.md
```

`0000-template.md` を複製し、下の索引に追加する。抑制の直前行には `// Waiver: WVR-NNNN` を置く。ファイル単位の抑制は waiver があっても禁止する。
