# ADR 0003 — セーブは進行と火と石の印だけ

- 状態: 受理
- 日付: 2026-10-25
- Issue: #59
- 影響する規則: ARC-009、ARC-004、ARC-010

## 文脈

ARC-009 は、保存するのは進行であり、盤の粒を保存するかは製品のセーブを書く ADR で決める、と残していた。火の印と石の印は発見だが、反応が書く場所は `Board` である。進行の財布、買った油と木と溶岩、蛇口は `Progression` にある。

2026-10-25 に施主が、盤の粒は保存せず、火と石の印は進行と一緒に残し、`q` と `Ctrl+C` で書く、と決めた。

## 決定

版 1 の文字列は、所持、倍率、油、木、溶岩、蛇口、火の印、石の印だけを持つ。盤の粒、筆、テーマ、一時停止、自動描画は持たない。読めない版と壊れた文字列は `Archive.Outcome.rejected` で返し、App が 1 行出して新規で始める。ファイルが無いときは新規で、行は出さない。ファイルの読み書きは `SaveStore` だけが行い、終了の `q` と `Ctrl+C` で書く。

## 強制

planned。文字列の往復は Swift Testing が見る。形式そのものを拒む機械はまだ無い。機械が版と項目の欠落を拒くまで、ARC-009 は planned のままである。

## 結果

得られるもの:

- 次の起動で、所持、倍率、購入、蛇口、火と石の印が続く
- 盤の絵はセッションのあいだだけにある

失うもの:

- 終了すると、描いた粒は戻らない
- 端末を閉じただけで、`q` も `Ctrl+C` も通らない終わり方は、最後の終了から先を残さない

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 盤の粒も保存する | 粒は毎 tick で動き、端末の大きさで落ちる。プレステージと `c` が粒を手放す側である |
| 読めないファイルを初期値として黙って読む | ARC-009 が、読めない版を既定値へ落とすことを禁じている |
| 火と石の印を盤に残したまま保存しない | 発見が次の起動で消える。印は進行の一部である |
